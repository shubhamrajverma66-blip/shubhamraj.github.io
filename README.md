# Shubham Raj Portfolio

A maroon + black legal/MUN portfolio inspired by the reference design.

## Files
- `index.html` — main portfolio
- `style.css` — responsive maroon/black styling
- `script.js` — reveal animations, cursor glow and mobile menu

## Before publishing
1. Open `index.html`.
2. Replace `YOUR_EMAIL@example.com` with your email.
3. Replace the LinkedIn URL with your actual LinkedIn profile.
4. Add a profile photo/CV later if desired.

## GitHub Pages
Create a GitHub repository named `shubhamraj.github.io` (or any repo if using a project page), upload these files, then enable GitHub Pages from Settings → Pages.
